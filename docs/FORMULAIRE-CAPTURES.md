# Captures comparatives du formulaire de devis

> Généré par `node tools/compare-formulaire.mjs` — ne pas éditer à la main.

Les quatre triptyques ci-dessous sont produits selon le protocole décrit en tête de
`tools/compare-formulaire.mjs` : mêmes données injectées, même étape (vérifiée avant
capture), même position de défilement, en-tête collant neutralisé à l'identique, polices
chargées.

**Ce document n’affirme pas que les deux formulaires portent les mêmes champs.** Les
différences fonctionnelles imposées sont listées dans `docs/FORMULAIRE-DIFFERENCES.md`,
une par une, avec leur motif.
